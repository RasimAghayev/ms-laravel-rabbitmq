# Support

## Where to ask

- **Bug or something broken:** open an issue using the "Bug Report"
  template — include the Docker image tag/stack version, steps to
  reproduce, and expected vs. actual behavior.
- **Feature idea:** open an issue using the "Feature Request" template
  and describe the use case before opening a PR (see `CONTRIBUTING.md`).
- **Security vulnerability:** do **not** open a public issue — see
  `SECURITY.md` for private reporting.
- **Accessibility barrier:** see `ACCESSIBILITY.md`.

## Response time

This is a personal project maintained on a best-effort basis — there is
no SLA and no office hours. There is no commercial support offering.

## Before asking

- Check `README.md` for the current architecture and "Running it" steps.
- Check `docs/TECHNICAL_DEBT.md` and `docs/ARCHITECTURE.md` — your
  question may already be a documented, known, intentional limitation
  rather than a bug.
